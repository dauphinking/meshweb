# HWZ Mining Screening Media

Source code for **[www.screenmesh.org](https://www.screenmesh.org)**, the website of HWZ Industrial Technology (Shanghai), a supplier of mining screening media and wear parts.

## Products

- [Vibrating screen panels](https://www.screenmesh.org/en) for coal, copper, gold and hard rock mining
- [Polyurethane screen panels](https://www.screenmesh.org/en/blog/polyurethane-screen-panel-properties) and rubber screen panels
- Dewatering screen panels for sand, coal fines and tailings
- Welded wire, woven wire and perforated plate screens
- Quarry screen mesh and aggregate screen media

Custom panels are made to fit any vibrating screen. We export to Australia, Southeast Asia, Africa, Peru and Chile.

Site languages: [English](https://www.screenmesh.org/en) · [Español](https://www.screenmesh.org/es) · [Français](https://www.screenmesh.org/fr) · [Русский](https://www.screenmesh.org/ru) · [العربية](https://www.screenmesh.org/ar)

## Development

Built with Next.js 15 (App Router) and deployed on Vercel.

```bash
pnpm install
pnpm dev
```

The inquiry form needs `RESEND_API_KEY` set. `NOTIFY_EMAIL` is optional and adds a CC address.
